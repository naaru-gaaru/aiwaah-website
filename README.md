# AiWaah! - Financial Genie 🧞‍♂️

**AiWaah** is a conversational AI interface designed to act as a personal "Financial Genie," helping users navigate wealth management, taxes, and cross-border financial planning (US/Canada).

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Theme](https://img.shields.io/badge/theme-Royal_Genie-purple.svg)

## 🌟 Project Overview

This repository hosts the frontend web interface for AiWaah. It is built with a "No-Framework" philosophy to ensure maximum performance, compatibility, and ease of deployment.

### Key Features
*   **Royal Genie Theme**: A premium UI featuring Deep Royal Purple gradients, Gold accents, and distinct "Aladdin-style" typography.
*   **App Shell Architecture**: A stable, Flexbox-based layout with fixed header/footer and scrollable chat area.
*   **Mobile-Optimized**: Responsive design that adapts to mobile viewports with specific touch-friendly adjustments.
*   **WCAG Compliant**: High-contrast text ratios (AAA/AA) for accessibility.

## 🛠 Technical Stack

*   **HTML5**: Semantic structure.
*   **CSS3**: Custom "Royal Genie" theme without external libraries (Tailwind/Bootstrap).
*   **JavaScript (Vanilla)**: Handles chat interactions, API calls to the backend, and UI state.
*   **Assets**: Optimized PNGs for Logos and Icons.

## 🚀 Deployment

This project is optimized for static hosting providers like **Vercel** or **Netlify**.

### Deployment Steps
1.  **Commit Changes**: Ensure all changes are committed to the `main` branch.
2.  **Push to GitHub**:
    ```bash
    git push origin main
    ```
3.  **Automatic Build**: Vercel/Netlify will detect the push and deploy the new version.
